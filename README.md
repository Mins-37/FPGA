# HX4S20 TF卡图片播放器

基于EG4S20BG256开发板：FAT32 TF卡 → SPI → BMP解析/缩放 → SDRAM双缓冲 → HDMI视频与48kHz测试音。

**当前为上板验收通过的FAT32稳定版本，动画功能尚未开始，Flash固化尚未完成。**

## 已实现

- FAT32根目录1～32张24位非压缩BMP，按8.3短文件名排序，支持文件碎片和根目录跨簇。
- KEY2手动切图、KEY4手动/自动轮播，淡出→换帧→淡入。
- 不同分辨率等比缩放至640×480并居中补黑边，最近邻采样。
- 运行时间、图片编号、模式、参数和滚动字幕叠加。
- 拨码亮度/对比度调节、48kHz HDMI测试音和实际PCM波形叠加。

## 下载与测试

1. 保持TF卡为FAT32。将[test_images](test_images)中的001.BMP～005.BMP放到卡根目录；先备份并移走其他BMP，避免目录计数混入旧文件。
2. 将[当前BIT](td_project/tf_bmp_scaler.bit)下载至SRAM，复位后应显示IMG 01/05。
3. KEY2切换五张图片，KEY4开启自动轮播，ERR应保持0。

KEY1复位。文件建议命名001.BMP～032.BMP；增加或删除图片后复位重新识别。不支持子文件夹、exFAT、FAT16、GPT或原生GIF/MP4。

详细格式限制和开关映射见[使用说明](使用说明.md)。

## 构建与验证

- 工具：TD 6.2.1 SP1；器件：EG4S20BG256。
- 工程入口：[td_project/tf_bmp_scaler.al](td_project/tf_bmp_scaler.al)。命令行可使用TD的run.exe执行[build.tcl](build.tcl)。
- 当前约束下时序：建立余量+0.117ns，保持余量+0.011ns；详见[报告](td_project/tf_bmp_scaler.timing)。
- 资源：13077/19600 LUT、44/64 BRAM、8/29 DSP。
- 16项仿真通过，播放器联动逐像素检查6帧、共1843200个像素。测试源和运行说明见[sim/fat32](sim/fat32)，结果见[仿真结果](仿真结果.md)。
- 用户已反馈：五张图、手动/自动切换、ERR:0、字幕、参数调节、音频及稳定性测试均正常。这是硬件反馈记录，仿真不替代真实SPI/SDRAM/HDMI验证。
- 尚待完成：Flash固化及断电重启验收。
