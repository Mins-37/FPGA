# HX4S20 FPGA 多媒体播放器 · 最终演示版

基于 HX4S20 / EG4S20BG256，使用 TF 卡、SDRAM 和 HDMI 实现图片、动画、音乐及同步音视频播放。

**最终验收：用户已确认 Flash 固化成功、连续运行正常、上电启动接近即刻。** 启动为用户实测描述，未进行仪器计时；早期约17秒的记录不代表当前最终版。纯净模式已包含在最终固件中，29项本轮仿真及最终时序审计通过。

## 已完成功能

- SPI 读取 FAT32 TF 卡；24位非压缩 BMP 解析、SDRAM 双缓冲和 640×480 HDMI 显示。
- 最多32个媒体文件扫描，上一项/下一项、图片自动轮播、菜单翻页和选中播放。
- 时间信息、动态滚动字幕、多图层叠加、图片淡入淡出、不同尺寸图片等比例缩放。
- 四个拨码开关控制亮度/对比度；音量调节、静音、48kHz HDMI 音频、实际音频波形和8频点频谱。
- 转换后的 ANM 动画、WAV 音乐、AVM 视频音画同步；播放进度及暂停/继续。
- 长按 KEY2 后松开切换纯净/完整显示，菜单始终可以呼出。

## 快速使用

最终固件：[`release/tf_bmp_final.bit`](release/tf_bmp_final.bit)。TD 工程：[`td_project/tf_bmp_scaler.al`](td_project/tf_bmp_scaler.al)。

TD Download 选择 `PROGRAM FLASH`，添加并选中最终 BIT 后运行；成功后断电重启验收。媒体仍从 TF 卡读取，固化不包含个人素材。

| 操作 | 功能 |
| --- | --- |
| KEY1 | 复位；上电默认完整显示 |
| KEY2 短按后松开 | 下一项；菜单内向下 |
| KEY3 短按后松开 | 上一项；菜单内向上 |
| 单独长按 KEY2 约1秒后松开 | 完整/纯净模式；菜单打开时仅向下选择 |
| KEY2+KEY3 同时长按约1秒 | 打开/关闭菜单，组合键优先 |
| KEY4 短按 | 图片手动/自动；其他媒体暂停/继续；菜单内确认 |
| KEY4 单独长按后松开 | 静音/恢复 |
| 先按住 KEY4，再按 KEY2/KEY3 | 音量增加/减小，可连续调节 |
| SW1～SW4 | 亮度与对比度 |

## 格式与边界

开发板不直接解码 MP3、MP4 或 GIF，先使用 `tools/` 转换为 WAV、AVM 或 ANM。AVM 默认256×192、10fps，RGB565配48kHz双声道PCM16音频；当前转换工具单段最长14秒，兼容160×120模式最长20秒，单文件不超过16MiB。HDMI输出为640×480，视频源分辨率与输出分辨率需区分。菜单使用 FAT32 8.3 短文件名，最多32项，不显示中文长文件名。
