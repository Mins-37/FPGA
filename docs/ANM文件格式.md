# HXA1动画文件格式

512字节头部，其后顺序存储完整RGB565帧。所有多字节整数均为小端。

|偏移|长度|含义|
|---|---|---|
|0|4|ASCII HXA1|
|4|2|宽160|
|6|2|高120|
|8|2|目标帧率5或10|
|10|2|总帧数1～400|
|12|4|每帧字节数38400|
|16|4|文件总字节数512+总帧数×38400|
|20|2|像素格式1，RGB565|
|22|2|版本1|
|24～511|488|保留，转换工具写0|

帧按从上到下、从左到右排列。一个像素为16位：R[15:11]、G[10:5]、B[4:0]，低字节在前。每帧75个512字节扇区，无压缩、无帧间差分、无音轨。

开发板将每个源像素复制为4×4像素，写入640×480 RGB888 SDRAM帧缓存。展开5/6位颜色时复制高位至低位。
