# AVM1 预转换音画容器

AVM 为 FAT32 根目录 8.3 文件名扩展名，播放器将它同时标记为动画和音频。单文件上限 16MiB，工具限制160×120 最多 20 秒、256×192 最多 14 秒。全部整数小端。

## 视频区

前 512 字节沿用 HXA1 动画头，后接 N 帧 160×120 或 256×192 RGB565，分别为 75 或 192 个扇区/帧。头偏移：

|偏移|类型|数值|
|---|---|---|
|0|4 bytes|HXA1|
|4|uint16|160 或 256|
|6|uint16|120 或 192|
|8|uint16|10|
|10|uint16|帧数 N|
|12|uint32|38400 或 98304|
|16|uint32|**视频区字节数** 512+N×frame_bytes，不含 WAV 区|
|20|uint16|RGB565 格式标记 1|
|22|uint16|版本 1|
|24|4 bytes|AVM1|
|28|uint32|48000|
|32|uint16|2 声道|
|34|uint16|16 位|
|36..511|bytes|0|

从偏移 512 开始按帧、按行存储 RGB565，小端，高 5 位红、中 6 位绿、低 5 位蓝。画面从上到下。

## 音频区

音频首扇区为 1+N×frame_bytes/512，即字节偏移 512+frame_bytes×N。这里存一个完整的标准 44 字节头 PCM WAV：48000Hz、stereo、16 位，data 大小 **N×4800×4**。

容器总大小为 512+N×frame_bytes+44+N×19200 字节。FAT32 文件大小记录整个容器大小。末扇区未占满的部分由文件系统扇区数据模型补齐，不属于音轨。

每 4800 个立体声采样对应一帧。转换后需要校验 PCM 采样数和视频帧数完全对应。音频先完成重采样，不把压缩音频送入 FPGA。

## 播放

两个读取器使用同一个虚拟文件索引，分别寻址视频区和 WAV 区；扇区仲裁器保持所有权直到事务结束、客户端释放，再选择下一个请求。音频优先补 FIFO，不在读卡事务中途切换客户端。视频按音频采样时间提交，跨时钟状态采用 bundled-data 握手。
