# 增强版实现说明

## KEY3 与导航

B1 引脚从开发板原始 DEMO/2_key_led/AA.adc、DEMO/6_cnt10/cnt10.adc 和整板测试约束核实。KEY3 消抖后设置上一项方向，和 KEY2 共用待处理导航请求。预先寄存上下索引、留出两周期稳定时间，再选择文件属性，缩短原先索引运算到媒体类型选择的组合路径。

## 进度

wav_read 在 HDMI 音频时钟域统计实际 FIFO pop，按 WAV data_size/4 循环。总样本数从 SD 域通过 bundled-data 握手传输。media_progress 复用一个 32 位恢复除法器计算十分之一秒及 400 像素进度，不放置三个大组合除法器。三个结果同时更新，OSD 在场边界锁存；暂停为黄色，播放为绿色，非 WAV/VID 隐藏。

## 256×192

RGB565 单帧 98304 字节、192 个扇区。源行刚好一个扇区；256 像素行缓存仍在一个 BRAM 中。水平和垂直按 3、2 重复，生成 640×480。原 160×120 使用 4 倍展开，保持兼容。帧偏移及 WAV 区偏移按 75/192 扇区切换。

高分辨率最多 140 帧，视频数据和每帧 4800 组 PCM 合计不超过 16MiB。工具以 14 秒为限。音频每 4800 组推进视频一帧，仍为 10fps 音频主时钟同步。

## FAT32

两个最近簇游标保留视频/音频读取位置。精确命中直接使用，连续下一簇只追踪一条 FAT 链；其他地址退回原稀疏检查点。切换文件、重扫、复位和加载中止使游标失效。合法簇判断及游标选择分周期完成，不改变 FAT32 范围和错误检查。

## 时钟约束

参考 50MHz、SD 100MHz、SDRAM 50MHz、HDMI 像素 25MHz 不变。采用官方 fix_hold 阶段修复实际同域保持路径。视频 PLL 和系统 PLL 之间仅通过异步 FIFO、多级控制同步器和 bundled-data req/ack 总线通信。

timing.sdc 仅对 video_clk 与 sd_card_clk/ext_mem_clk 之间双向 hold/removal 检查设置四条有范围的例外。建立/最大延迟检查仍保留；同一系统 PLL 的 SD↔SDRAM 建立和保持检查均保留。约束先检查三个时钟是否非空，缺失时直接报错，避免空集合变成无范围例外。未使用全局保持例外或降低工作频率。

审计报告 tf_bmp_scaler.audit.timing 可确认 video↔SD 的 Max 路径仍分析、Min 为 0 条；SD↔SDRAM 的 Max/Min 均有实际分析路径。跨域的正确性还依赖 FIFO Gray 指针/握手结构，不能仅靠 STA 判定。

## 验证边界

行为仿真不模拟 SD 电气特性、卡内部不确定延迟、加密 HDMI 核、真实 SDRAM 和显示器延迟。本增强版需上板确认，旧版通过不代替本次验收。
