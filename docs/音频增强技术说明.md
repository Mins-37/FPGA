# 音频增强实现

所有新运算在 25MHz 像素域完成。原音频源选通后，立体声增益处理数据及 valid 同步延迟两拍再送 HDMI，约 80ns，不改变源读取节拍、48kHz ACR 或作为视频主时钟的已消费采样计数。

增益为无符号 Q8 的 0..256，目标为档位乘 32。每个实际采样以一步向目标逼近，最大全程 256/48000 秒。24 位有符号样本与十位正系数相乘，34 位中间积算术右移八位；100% 无损、0% 和静音收敛后严格为零，正负满量程不溢出。

按键同步后向量消抖 10ms。短 KEY4 松开生成暂停事件，长按松开生成静音事件；KEY4 与 KEY2/3 组合锁定该次手势，防止释放次序造成误切换或误暂停。音量首次组合立即响应，持续按每 250ms 一档。导航事件伸展为 80ms 低脉冲，再由 SD 域三级同步和沿检测接收，消除重复消抖计数器，原物理引脚和开关功能不变。

Goertzel 逐个处理八频点，共享乘法器，256 点矩形窗。输入使用调节后左声道高八位；Q14 系数，22 位递归状态，38 位乘积。同步 RAM 存储每频点两级状态，复位后八拍清零，不异步复位 RAM。每块结束计算实部、虚部，以绝对值和近似幅值，转对数高度。窗口幅值近似和八位输入用于视觉展示，不作为精密幅度计量。

频谱逐频点提交，稳定标志防止显示半更新结果；频谱柱在 VS 帧边界快升、每帧降两像素，八根中心频率从 187.5Hz 至 18kHz。波形检测连续 256 个近零样本后清除旧轨迹，避免静音仍保留陈旧波形。波形使用两份镜像同步 BRAM，增加一拍读取，RGB、DE、VS 与坐标同拍延迟以对齐。

时钟及 CDC 约束沿用前版，未降低时钟或增加全局 false path。最终时序报告必须建立和保持均通过后才交付。
